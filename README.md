# phro-prompt-nudge

내 입력과 대화 맥락을 관찰해서 **더 나은 질문·프롬프트를 제안하는** Claude Code mod입니다.

Claude가 답을 마칠 때마다 최근 대화 8줄을 Haiku에 보내 두 가지를 받아 입력창 위에 띄웁니다. 대화는 트랜스크립트에서 읽지 않고 mod가 직접 기록합니다. 사람이 입력한 프롬프트와 Claude의 최종 답변만 담기므로, 다른 도구·훅이 끼워 넣는 지침(skill 본문, system reminder, 명령 안내문 등)은 Haiku에 섞이지 않습니다.

- `💡` 방금 보낸 프롬프트에서 부족했던 점(맥락·제약·성공 기준·범위·모호함)을 한 줄로
- `→` 지금 보내면 좋을 다음 프롬프트

**Use**를 누르면 제안이 입력창 커서 위치에 들어가고(쓰던 초안은 지워지지 않음), **Hide**를 누르면 사라집니다. 새 프롬프트를 보내면 이전 제안은 지워집니다. 이미 충분히 좋은 프롬프트였다면 아무것도 띄우지 않습니다. 사람이 새 프롬프트를 보내지 않은 턴(백그라운드 작업 알림, 예약 작업 등)은 분석하지 않고, 분석 중에 새 프롬프트를 보내면 이전 결과는 버립니다.

## 설치

```bash
claude plugin marketplace add ThatsHoon/phro
claude plugin install phro-prompt-nudge@phro
```

## 사용

| 명령 | 동작 |
|---|---|
| `/nudge` | 제안 켜기/끄기 (설정은 세션이 바뀌어도 유지) |
| `/nudge stats` | 지금까지 Haiku 호출 수·실패 수·입출력 토큰 누적과 호출당 평균 |

## 비용

사람이 새 프롬프트를 보낸 턴이 끝날 때마다 Haiku를 한 번 호출합니다(입력은 최근 대화 8줄·줄당 600자 이내, 출력 최대 300 토큰). 실제 사용량은 `/nudge stats`로 확인합니다. 서브에이전트 턴, 중단·에러로 끝난 턴에서는 호출하지 않습니다.
