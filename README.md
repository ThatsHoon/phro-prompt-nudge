# phro-prompt-nudge

내 입력과 대화 맥락을 관찰해서 **더 나은 질문·프롬프트를 제안하는** Claude Code mod입니다.

Claude가 답을 마칠 때마다 최근 대화 8줄을 Haiku에 보내 두 가지를 받아 입력창 위에 띄웁니다. 대화는 트랜스크립트에서 읽지 않고 mod가 직접 기록합니다. 사람이 입력한 프롬프트와 Claude의 최종 답변만 담기므로, 다른 도구·훅이 끼워 넣는 지침(skill 본문, system reminder, 명령 안내문 등)은 Haiku에 섞이지 않습니다.

- `💡` 방금 보낸 프롬프트에서 부족했던 점(맥락·제약·성공 기준·범위·모호함)을 한 줄로
- `→` 지금 보내면 좋을 다음 프롬프트

**Use**를 누르면 제안이 입력창에 채워지고, **Hide**를 누르면 사라집니다. 새 프롬프트를 보내면 이전 제안은 지워집니다. 이미 충분히 좋은 프롬프트였다면 아무것도 띄우지 않습니다.

## 설치

```bash
claude plugin marketplace add ThatsHoon/phro
claude plugin install phro-prompt-nudge@phro
```

## 사용

| 명령 | 동작 |
|---|---|
| `/nudge` | 제안 켜기/끄기 (세션 단위, 새 세션은 켜진 상태로 시작) |

## 비용

답변이 끝날 때마다 Haiku를 한 번 호출합니다(최대 300 토큰). 서브에이전트 턴, 중단·에러로 끝난 턴에서는 호출하지 않습니다.
